# Phase 8 — Polish, Security and Performance

## Goal

Make the app production-ready.

## UI Polish

Add:
- skeleton loading states
- empty states
- error boundaries
- toast notifications
- animations
- command palette if useful
- responsive fixes
- table filters and sorting
- better detail drawers
- activity feeds

## Security

Add:
- Firestore security rules
- role-based access prep
- no secrets in frontend
- input validation
- API rate limits
- auth checks on callable functions
- audit logs

## Performance

Optimize:
- Firestore queries
- pagination
- table virtualization if needed
- code splitting
- lazy loading
- memoization where useful

## Compliance

Add:
- delete contact/company
- export data
- suppression list management
- source tracking
- opt-out wording
- warning for B2B outreach use

## Acceptance Criteria

- App feels polished
- No obvious security leaks
- Handles loading/error states
- Firestore rules exist
- README is complete
